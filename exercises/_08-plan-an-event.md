## Exercise 8: Plan a departmental event {#exercise-8-plan-a-departmental-event}

::: {.callout-note collapse="true" appearance="minimal" icon=false title="Open exercise"}

**Scenario.** You have an initial event brief, but the organisers still need a practical plan.

**Attach:** [06_simulated_event_brief.md](materials/06_simulated_event_brief.md).

**Try this prompt:**

```text
Turn the attached event brief into a practical preparation checklist.

Group tasks into what is already assigned, what still needs an owner, and decisions that are still open. Include stated deadlines and flag dependencies (for example, what must happen before invitations can be sent). Do not assume that rooms, spending or hybrid arrangements have been approved.
```

**Then try:** Ask for a draft agenda that fits the event objectives and duration, clearly labelled as a proposal.

**Check:** Did it preserve the difference between known facts, suggestions and unconfirmed arrangements?

**Want to reuse this?** Try [Exercise 13](#exercise-13-use-a-project-across-separate-chats) to create an event Project and update the plan across two chats.

:::
