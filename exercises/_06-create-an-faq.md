## Exercise 6: Turn a procedure into an FAQ {#exercise-6-turn-a-procedure-into-an-faq}

::: {.callout-note collapse="true" appearance="minimal" icon=false title="Open exercise"}

**Scenario.** Colleagues keep asking the same questions about booking rooms, equipment and catering.

**Attach:** [05_room_booking_procedure_v2.md](materials/05_room_booking_procedure_v2.md).

**Try this prompt:**

```text
Create a short FAQ for colleagues booking an event, based only on the attached procedure.

Include questions about room booking, hybrid/AV support, catering, accessibility and cancellations. Use plain language and refer to the source section for each answer. Mark anything the document does not specify instead of filling in the gaps.
```

**Then try:** Ask for a one-page checklist instead of an FAQ.

**Check:** Did it capture working-day deadlines accurately? Did it add rules that were not in the document?

:::
