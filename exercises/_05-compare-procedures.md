## Exercise 5: Compare two versions of a procedure {#exercise-5-compare-two-versions-of-a-procedure}

::: {.callout-note collapse="true" appearance="minimal" icon=false title="Open exercise"}

**Scenario:** A room-booking procedure has been updated. You want to know what changed and which version applies.

**Use:** [04_room_booking_procedure_v1.md](materials/04_room_booking_procedure_v1.md) and [05_room_booking_procedure_v2.md](materials/05_room_booking_procedure_v2.md).

**Try this prompt:**

```text
Compare the two attached versions of the room-booking procedure.

Make a short table showing the important changes, including deadlines and accessibility arrangements. Explain when each version applies. Base the explanation on the documents, and note which rules have not changed.
```

**Then try:** Ask which version applies to a request submitted on **28 October 2026** for an event taking place on **20 November 2026**.

**Check:** Did it notice the rule about when the updated procedure takes effect, rather than using only the event date?

:::
